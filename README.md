# BobWay Ambassador Suite

Welcome to the **BobWay Ambassador Suite**! 🚀

This repository demonstrates how BobWay equips your Bob coding assistant with verified domain skills, engineering guardrails, and platform awareness.

## Included Skills in `examples/skills/`:

### 1. **BobWay Platform Ambassador** (`bobway`)
- Answers questions about BobWay, its curated skills marketplace, and developer experience.
- Details the 3-step onboarding flow: Explore -> Get Key -> Connect in Bob.
- Highlights live platform capabilities and upcoming future roadmap goals (Workspace Propagation, Live Sharing, Governance).

### 2. **Next.js App Router Architecture Expert** (`nextjs-app-router-expert`)
- Enforces React 19 Server Component boundaries and zero client-bundle leakage.
- Standardizes secure Server Actions mutation flows with schema validation.

### 3. **PostgreSQL Performance & Storage Architect** (`postgresql-performance-architect`)
- Database indexing, query planning, and zero-downtime migration guidelines.

### 4. **LLM Prompt Guardrail & Security Auditor** (`llm-prompt-guardrail-auditor`)
- Security guardrails, prompt injection defenses, and safe parameter validation.

## Indexing into BobWay

You can index this workspace directly from the BobWay Web Dashboard:
1. Navigate to **Workspaces -> New Workspace**.
2. Connect your GitHub repository (or enter repository path).
3. Set Skills Directory to `examples/skills/`.
4. Click **Publish Workspace**. BobWay will automatically index each skill folder (`bobway`, `nextjs-app-router-expert`, etc.).
